# Launch checklist

## Business acceptance

- [ ] Eram approves the name, wordmark, colors, copy, and generated art.
- [x] Add owner-supplied Ghana and U.S. phone numbers.
- [ ] Confirm WhatsApp availability, email, and location if these will be published.
- [ ] Replace or clearly approve all illustrative vehicle art.
- [ ] Verify actual vehicles, rentals, merchandise, and service details.
- [ ] For a real featured vehicle, replace concept close-ups with photos of that exact car and verify each described detail.
- [ ] Decide the real inquiry or booking destination and connect it.

## Product completion

- [ ] Add live inventory only if Eram can keep it current.
- [ ] Add rental booking rules and a receiving workflow if bookings are enabled.
- [ ] Add privacy and terms pages for the final data collection design.
- [ ] Run keyboard, screen reader, desktop, mobile, and reduced-motion checks.
- [ ] Check image licensing and approve the final campaign assets.

## Deployment

- [ ] Set a domain and hosting target.
- [ ] Build and deploy the static site.
- [ ] Verify the deployed site and every contact path in production.
